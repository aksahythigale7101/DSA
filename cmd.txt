revert vs reset

हे खूप important आहे:

git revert
    ↓
नवीन commit तयार करतो
    ↓
Safe for shared/GitHub branch ✅
git reset
    ↓
Branch history मागे नेतो
    ↓
Shared GitHub branch साठी काळजीपूर्वक वापरावा ⚠️


--GitHub वर already pushed commit undo करायचा असेल → git revert
--Local, अजून push न केलेला commit मागे घ्यायचा असेल → git reset उपयोगी ठरू शकतो.
